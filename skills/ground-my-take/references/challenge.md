# Challenge — technique

Executes Compass's EAST direction ("what competes with X?") — see `references/compass.md`.

## Concept

Grounded in Karl Popper's falsificationism: a test only counts if it carries real risk
of negating the claim — a test designed to always confirm is worthless. Applied to a
take, the move is to actively seek the condition under which the claim would be false,
not gather more support for it. Toulmin's argument model supplies the structural slot:
every argument carries a rebuttal position, found by examining objections to its
grounds, warrant, and backing. The practitioner form is steelmanning — state the
strongest version of the opposing case, then genuinely try to break the claim, not
perform token objections.

## Guardrail

Two failure modes, both real:

- **A rhetorical question isn't a Challenge.** Per Popper's own criterion, if the
  user's answer could only ever confirm the take, it wasn't a real test — find the
  version of the question that could actually break it.
- **A Challenge stays a question.** Surfacing the competing case is the whole job;
  delivering the counter-argument's conclusion on the user's behalf is not — same
  "never your own opinion" rule `grounding` holds everywhere else, aimed here instead
  of at a source.

## Worked example

The user proposes that open-plan offices always hurt deep work. Ask: "would that hold
for a team doing mostly quick synchronous coordination rather than long solo focus
blocks — where would this connection actually break down?"
